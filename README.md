# ☁️ Azure Labs

This repository contains hands-on Microsoft Azure labs covering core infrastructure, networking, security, monitoring, backup, and Kubernetes services.

## 📚 Lab Index

| # | Lab | Description | Status |
|---|-----|-------------|--------|
| 01 | [Azure VM](01-Azure-VM/) | Deploy and manage Azure Virtual Machines | ✅ Completed |
| 02 | Virtual Network | Create VNets, Subnets, DNS settings, and network segmentation | ⏳ Planned |
| 03 | Network Security Groups (NSG) | Configure inbound/outbound security rules and traffic filtering | ⏳ Planned |
| 04 | Load Balancer | Deploy Azure Load Balancer and distribute traffic across virtual machines | ⏳ Planned |
| 05 | Storage Account | Create and manage Storage Accounts, Blob Storage, File Shares, and Access Keys | ⏳ Planned |
| 06 | Azure Backup | Configure backup policies and protect Azure Virtual Machines | ⏳ Planned |
| 07 | Recovery Services Vault | Create and manage Recovery Services Vault for backup and disaster recovery | ⏳ Planned |
| 08 | Azure Monitor | Monitor resources using Metrics, Logs, Alerts, and Log Analytics | ⏳ Planned |
| 09 | Azure Bastion | Securely connect to Azure Virtual Machines without exposing public IP addresses | ⏳ Planned |
| 10 | Azure Kubernetes Service (AKS) | Deploy and manage Kubernetes clusters using Azure Kubernetes Service | ⏳ Planned |
